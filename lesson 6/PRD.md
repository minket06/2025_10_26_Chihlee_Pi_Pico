# 智慧家居監控儀表板 - 產品需求文件 (PRD)

## 專案概述

本專案旨在開發一個基於 Streamlit 的即時監控儀表板,用於顯示智慧家居的感測器資料。系統透過 MQTT 協定訂閱感測器數據,並以視覺化方式呈現給使用者。

## 系統角色定位

- **角色**: MQTT Subscriber (訂閱者)
- **技術棧**: Python + Streamlit + MQTT + Pandas
- **部署環境**: Raspberry Pi

---

## 功能需求

### 1. 即時資料顯示

#### 1.1 電燈狀態監控
- 顯示電燈的開關狀態 (ON/OFF)
- 使用視覺化指示器 (如:綠色=開啟,灰色=關閉)
- 即時更新狀態變化

#### 1.2 溫濕度監控
- **顯示項目**:
  - 客廳溫度 (°C)
  - 客廳濕度 (%)
- **顯示方式**:
  - 當前數值以大字體顯示
  - 歷史趨勢以折線圖呈現
- **圖表規格**:
  - X 軸: 日期與時間 (格式: YYYY-MM-DD HH:MM:SS)
  - Y 軸: 溫度/濕度數值
  - 支援雙 Y 軸或分開顯示

### 2. 資料持久化

#### 2.1 資料儲存
- **格式**: Excel 檔案 (.xlsx)
- **儲存內容**:
  - 時間戳記
  - 電燈狀態
  - 溫度數值
  - 濕度數值
- **檔案命名**: 建議使用時間戳記,如 `sensor_data_YYYYMMDD.xlsx`
- **更新機制**: 每次接收到新資料時自動追加儲存

## 技術規格

### MQTT 訂閱設定
- **Broker**: (待定義)
- **Topics**: 
  - 電燈狀態: `home/living_room/light`
  - 溫度: `home/living_room/temperature`
  - 濕度: `home/living_room/humidity`
- **QoS**: 建議使用 QoS 1 (至少傳送一次)

### 資料格式
```json
{
  "timestamp": "2025-11-30 14:00:00",
  "light_status": "ON",
  "temperature": 25.5,
  "humidity": 60.2
}
```

## 使用者介面設計

### 頁面佈局
1. **標題區**: 應用程式名稱與當前時間
2. **狀態卡片區**: 顯示電燈狀態、當前溫度、當前濕度
3. **圖表區**: 溫濕度歷史趨勢圖
4. **資料表區**: (可選) 顯示最近的資料記錄

### 互動功能
- 目前版本: **僅顯示功能** (唯讀模式)
- 未來擴展: 可考慮加入控制功能 (如:遠端開關電燈)

---

## 非功能需求

- **效能**: 資料更新延遲 < 2 秒
- **可靠性**: 斷線後自動重連 MQTT Broker
- **可用性**: 介面簡潔直觀,適合非技術人員使用
- **擴展性**: 架構設計應便於未來新增更多感測器
